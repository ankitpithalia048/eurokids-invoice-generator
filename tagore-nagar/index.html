    ⚙ Google Sheet Sync Settings

    Paste your Google Apps Script Web App URL below. The app will save invoices to your sheet and load them back on every device.

    How to get this URL:

    1. Open your Google Sheet → Extensions → Apps Script
    2. Paste the code.gs file contents from the tagore-nagar folder
    3. Click Deploy → New deployment
    4. Type: Web app, Execute as: Me, Access: Anyone
    5. Click Deploy and copy the web app URL here

    Use a separate Google Sheet for Tagore Nagar so its invoices never mix with VIP Colony's. This URL is stored separately from the VIP Colony app's URL.
